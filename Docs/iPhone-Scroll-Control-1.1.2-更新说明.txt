iPhone Scroll Control 1.1.2 更新说明
====================================

发布日期：2026-08-31
适用系统：macOS 15 或更高版本
支持架构：Apple 芯片（arm64）与 Intel（x86_64）

本次修复
--------
1. 修复 iPhone 镜像隐藏后，点击原窗口区域会意外重新显示窗口的问题。
2. 隐藏或最小化动作开始时立即撤下悬浮预览，不再等待下一次定时刷新。
3. 操作前同时检查应用隐藏状态、窗口最小化状态和 WindowServer 屏幕状态。
4. 隐藏、最小化或窗口离开当前桌面后，工具暂停全部镜像快捷功能。
5. 窗口状态检查间隔从 0.5 秒缩短到 0.1 秒。

已有主要功能
------------
- Logitech G309 后侧键切换下一条视频，前侧键切换上一条视频。
- 上、下方向键切换视频，空格播放或暂停。
- 左方向键点赞，右方向键打开分享面板。
- 数字键 1–5 选择分享联系人，Enter 发送。
- 点击黄色最小化按钮、按 Command + M 或 Command + H 时先暂停视频。
- 聊天页不会拦截空格、数字和方向键。
- 登录 macOS 后自动运行。

升级说明
--------
打开 DMG，按住 Control 点击“安装.command”并选择“打开”。安装程序会备份旧版本、
替换应用并重新启动后台服务。由于应用使用本地签名，升级后如果快捷键或悬浮预览
没有反应，请在系统设置中重新确认辅助功能、输入监控、屏幕与系统音频录制权限。
