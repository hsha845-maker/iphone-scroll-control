iPhone Scroll Control 1.1.9
===========================

1.1.9 更新亮点
--------------
- 修复选择联系人后分享面板变为简化布局，导致 Enter 无法发送的问题。
- 支持识别仅显示“分享给 + 发送”的分享面板；鼠标选人后也可按 Enter 发送。
- 修复“首页 → 推荐”画面偶发识别失败，导致方向键无效并发出系统提示音的问题。
- 动态字幕或弹幕遮挡标签时，键盘和鼠标侧键仍可使用最近可靠的页面识别结果。
- 点击搜索、消息、分享或开始打字后仍会立即停用视频快捷键，避免影响输入。
- iPhone 镜像窗口最小化或隐藏时，悬浮预览会同步消失，不再挡住其他窗口。
- 隐藏或最小化后，所有镜像快捷操作都会暂停；点击原窗口区域不会重新唤出镜像。
- 隐藏或最小化后会真正停止屏幕采集，让菜单栏 sharing 状态结束；恢复窗口后自动恢复采集。
- 点击黄色最小化按钮、按 Command + M 或 Command + H 时，会先暂停视频再执行窗口操作。
- 恢复 iPhone 镜像窗口后不会擅自恢复播放。
- 优化悬浮预览圆角遮罩，去除四角黑边和面板投影。
- 增加视频页专用键盘快捷键，并保护聊天输入不被拦截。
- 改进分享面板操作：数字 1–5 选择前五位联系人，Enter 发送。
- 仅在同时识别到“首页”和“推荐”时启用视频控制快捷键。
- 搜索、聊天和其他页面不会拦截键盘输入。
- “分享给”弹窗出现后才启用数字 1–5 与 Enter；手动打开分享也支持。
- 分享弹窗中按右方向键可关闭弹窗；鼠标手动选人后也可以按 Enter 发送。
- 视频已经暂停时，隐藏或最小化窗口不会再次点击画面，避免恢复播放。
- 修复中文输入法按空格确认候选词时被播放/暂停快捷键拦截的问题。
- “首页”和“推荐”必须位于正确的底部、顶部区域才会启用视频快捷键。
- 开始打字后有 2 秒输入保护期，空格、方向键和数字键均交给输入法。
- OCR 短暂漏识别视频页时，隐藏或最小化仍会可靠地先暂停视频。
- 暂停后等待 0.35 秒再隐藏窗口，避免声音继续播放。
- 支持 Apple 芯片与 Intel 芯片 Mac 的通用安装包。

系统要求
--------
- macOS 15 或更高版本
- Apple 芯片或 Intel 芯片 Mac
- Apple「iPhone Mirroring / iPhone 镜像」
- 已在 iPhone 镜像中打开抖音

安装
----
1. 双击打开 DMG。
2. 按住 Control 点击“安装.command”，选择“打开”。
3. 安装程序会把应用复制到个人“应用程序”文件夹，并设置登录后自动运行。
4. 如果 macOS 阻止运行，请前往“系统设置 > 隐私与安全性”，找到安全提示并选择“仍要打开”。

必须开启的权限
--------------
在“系统设置 > 隐私与安全性”中，分别进入以下三个页面：

1. 辅助功能
2. 输入监控
3. 屏幕与系统音频录制

在每一页点击“+”，添加：
~/Applications/iPhone Scroll Control.app

三项权限全部开启后，运行 DMG 中的“重新启动.command”。

快捷键
------
- Logitech G309 后侧键：下一条视频
- Logitech G309 前侧键：上一条视频
- 键盘 ↓：下一条视频
- 键盘 ↑：上一条视频
- 空格：播放/暂停
- 键盘 ←：点赞
- 键盘 →：打开分享面板
- 分享面板中按 1、2、3、4、5：选择前五位联系人
- Enter：点击发送按钮
- Command + M：暂停视频后最小化 iPhone 镜像
- Command + H：暂停视频后隐藏 iPhone 镜像

使用限制与安全设计
------------------
- 视频快捷键仅在 iPhone Mirroring 位于前台、并同时识别到“首页”和“推荐”时生效。
- 分享数字键与 Enter 仅在识别到“分享给”弹窗时生效。
- 搜索、聊天及其他页面不会拦截正常打字。
- 离开 iPhone Mirroring 后，鼠标侧键保持浏览器前进/后退等原功能。
- 联系人位置按分享面板第一行的前五位计算；抖音界面改版后可能需要调整。
- 点击黄色最小化按钮时，程序也会先暂停当前视频。

鼠标按钮差异
------------
当前默认映射为后侧键 Button 3、前侧键 Button 4。不同鼠标或驱动可能报告不同编号，
如果侧键方向不正确，需要修改源码 Config 中的 nextButton 和 previousButton 后重新编译。

日志位置
--------
~/Library/Logs/iPhoneScrollControl.log
~/Library/Logs/iPhoneScrollControl.error.log

关于安全提示
------------
此分享版本没有使用付费 Apple Developer ID 签名和苹果公证，因此首次运行时 macOS
可能显示“无法验证开发者”。这是安装包的签名限制，不代表程序依赖了第三方工具。
